
# ✅ WordPress User Roles and Capabilities

WordPress has a built-in role management system that defines what users can and cannot do within a site. Here's an updated overview:


## 👑 Super Admin *(Multisite Only)*

* **Scope**: WordPress Multisite Network
* **Capabilities**:

  * Manage the entire network of sites.
  * Add, edit, and delete sites.
  * Install, update, and delete themes and plugins across the network.
  * Manage network users, settings, and updates.


## 🛠️ Administrator

* **Scope**: Single Site
* **Capabilities**:

  * Full site control.
  * Manage all posts, pages, users, comments, settings, themes, and plugins.
  * Assign roles to other users.
  * Install and update WordPress core, themes, and plugins.
  * Access advanced settings and customization options.


## ✏️ Editor

* **Scope**: Single Site
* **Capabilities**:

  * Publish, edit, and delete any posts and pages (own or others').
  * Manage categories, tags, and links.
  * Moderate comments.
  * Upload media files.
  * Cannot change site settings, themes, or install plugins.

## 🧑‍💻 Author

* **Scope**: Single Site
* **Capabilities**:

  * Publish, edit, and delete their own posts.
  * Upload media files.
  * Cannot manage posts of other users or moderate comments.


## 📝 Contributor

* **Scope**: Single Site
* **Capabilities**:

  * Write and edit their own posts.
  * Submit posts for review.
  * Cannot publish posts.
  * Cannot upload media files.


## 👤 Subscriber

* **Scope**: Single Site
* **Capabilities**:

  * Manage their own user profile.
  * Read posts and leave comments (if comments are enabled).
  * Cannot write posts or access admin features.
