
# 🎨 WordPress Theme

## 💡 What is a WordPress Theme?

A **WordPress theme** is a collection of files (*templates, stylesheets, scripts, images*) that control the **design, layout, and overall appearance** of a WordPress website.

### Themes define:

* 🎨 Site appearance (colors, fonts, headers, footers)
* 🧾 Content presentation (blog posts, pages, products)
* 🧭 User experience elements (menus, sidebars, navigation)

> **Note:** Changing a theme affects only the appearance — **not your content** (posts, pages, or users remain unchanged).

---

## 🧩 Key Parts of a WordPress Theme

| File             | Description                                    |
| ---------------- | ---------------------------------------------- |
| `style.css`      | Main stylesheet (required)                     |
| `index.php`      | Main template file (required)                  |
| `functions.php`  | Theme functions and custom features            |
| `header.php`     | Header section layout                          |
| `footer.php`     | Footer section layout                          |
| `sidebar.php`    | Sidebar layout                                 |
| `page.php`       | Template for static pages                      |
| `single.php`     | Template for single posts                      |
| `archive.php`    | Template for archive views                     |
| `screenshot.png` | Preview image shown in the WordPress dashboard |

---

## 🧱 Types of WordPress Themes

* 🆓 **Free Themes**: Available at [WordPress.org Themes Directory](https://wordpress.org/themes/)
* 💲 **Premium Themes**: Paid themes with more features and support
* 🛠️ **Custom Themes**: Fully customized for a brand or project
* 🧰 **Theme Frameworks**: Developer base themes (e.g., Genesis Framework)

---

## ⚙️ How Themes Work

When a theme is activated:

* WordPress uses the theme's **templates and CSS** to render the site.
* You can customize via:

  * 🎛️ *Appearance > Customize*
  * 🧩 *Theme Options Panel* (if available)
  * 🧱 *Full Site Editing (FSE)* — for block themes (WordPress 5.9+)

## 📥 How to Install a Theme

1. **From Dashboard**:
   Appearance > Themes > Add New

2. **Upload .zip file**:
   Appearance > Themes > Add New > Upload Theme

3. **Manual (FTP)**:
   Upload the theme folder to `/wp-content/themes/`
