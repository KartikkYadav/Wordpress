
# WordPress Theme

## What is a WordPress Theme?

A **WordPress theme** is a collection of files (templates, stylesheets, scripts, images) that control the **design**, **layout**, and **overall appearance** of a WordPress website.

### A theme defines:

* How your site looks (colors, fonts, headers, footers, etc.)
* How your content is displayed (blog posts, pages, products, etc.)
* User experience elements (menus, sidebars, navigation)

> 🔸 A theme affects the **site's appearance**, but **not the core content**.
> Your posts, pages, and users remain unchanged even if you change the theme.

---

## Key Parts of a WordPress Theme

| File Name        | Description                                     |
| ---------------- | ----------------------------------------------- |
| `style.css`      | Main stylesheet (required).                     |
| `index.php`      | Main template file (required).                  |
| `functions.php`  | Theme functions and custom features.            |
| `header.php`     | Displays the header section of the site.        |
| `footer.php`     | Displays the footer section of the site.        |
| `sidebar.php`    | Contains the sidebar layout.                    |
| `page.php`       | Template for standard pages.                    |
| `single.php`     | Template for single blog posts.                 |
| `archive.php`    | Template for category, tag, and date archives.  |
| `screenshot.png` | Preview image shown in the WordPress dashboard. |

## 🛠️ How Themes Work

When you **activate a WordPress theme**:

* WordPress uses the **theme's templates and CSS** to render your site.
* You can customize the theme via:

  * **WordPress Customizer**
    *(Appearance > Customize)*
  * **Theme Options Panel**
    *(if provided by the theme)*
  * **Full Site Editing (FSE)**
    *(available if it’s a block theme — WordPress 5.9 or later)*

## 🖥️ How to Install a WordPress Theme

You can install a WordPress theme in two main ways:

### **Method 1: Install via WordPress Dashboard**

#### **A. Install a Free Theme from the WordPress Repository**

1. Log in to your WordPress Admin Dashboard (`yourdomain.com/wp-admin`).
2. Go to **Appearance > Themes**.
3. Click the **Add New** button at the top.
4. Browse or search for a theme (e.g., **Astra**, **OceanWP**).
5. Hover over the theme and click **Install**, then click **Activate**.

#### **B. Upload a Theme (.zip File)**

1. Go to **Appearance > Themes**.
2. Click **Add New**, then click **Upload Theme**.
3. Click **Choose File** and select your `.zip` theme file.
4. Click **Install Now**.
5. Once uploaded, click **Activate**.

---

### **Method 2: Install via FTP (Advanced)**

1. **Unzip the theme .zip file** on your computer.
2. **Use an FTP client** (e.g., **FileZilla**) to connect to your website's server.
3. Navigate to the directory:
   `/wp-content/themes/`
4. **Upload the unzipped theme folder** into this directory.
5. Go to **Appearance > Themes** in WordPress and **activate** the theme.
