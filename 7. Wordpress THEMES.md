
# WordPress Theme

## What is a WordPress Theme?

A **WordPress theme** is a collection of files (templates, stylesheets, scripts, images) that control the **design**, **layout**, and **overall appearance** of a WordPress website.

### A theme defines:

* How your site looks (colors, fonts, headers, footers, etc.)
* How your content is displayed (blog posts, pages, products, etc.)
* User experience elements (menus, sidebars, navigation)

> 🔸 A theme affects the **site's appearance**, but **not the core content**.
> Your posts, pages, and users remain unchanged even if you change the theme.

---

## Key Parts of a WordPress Theme

| File Name        | Description                                     |
| ---------------- | ----------------------------------------------- |
| `style.css`      | Main stylesheet (required).                     |
| `index.php`      | Main template file (required).                  |
| `functions.php`  | Theme functions and custom features.            |
| `header.php`     | Displays the header section of the site.        |
| `footer.php`     | Displays the footer section of the site.        |
| `sidebar.php`    | Contains the sidebar layout.                    |
| `page.php`       | Template for standard pages.                    |
| `single.php`     | Template for single blog posts.                 |
| `archive.php`    | Template for category, tag, and date archives.  |
| `screenshot.png` | Preview image shown in the WordPress dashboard. |
